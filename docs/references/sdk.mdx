## Install

```bash variant="single"
bun add tardie
```

Most applications can import their actor definition, agent components, policies, and public types from `tardie/deprecated/core` and `tardie/deprecated/agent`:

```ts
import { actor } from "tardie/deprecated/core"
import { agentMethods, budget, codeMode, compact, messages, infer, nativeOutput, system, tool } from "tardie/deprecated/agent"
```

## Core primitives

The `tardie/deprecated/core` entry point exports the common actor and component types. Lower-level integrations can import each primitive directly:

